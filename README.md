# Zhang Group website

Static website for the Zhang Group (Department of Astronomy, University of Wisconsin–Madison),
hosted on GitHub Pages.

- Plain HTML + CSS, no build step. Edit the `.html` files and push.
- `publications.html` is a static page. To refresh it from the ADS/SciX library, open
  `local_generator.html` (kept local, not in this repo) via a local server and paste the output
  into `publications.html`.
